# Personal landing page

A terminal/Vim-styled personal site for Natan Moreira: experience, skills, projects and key takeaways. Built with Next.js (App Router), Tailwind CSS and a self-hosted JetBrains Mono.

## Run it

```bash
npm install
npm run dev     # http://localhost:3002
npm run build   # production build
npm run start   # serve the production build
npm run lint
```

## Edit the content

All copy lives in [`src/content/index.ts`](src/content/index.ts), typed by [`src/content/types.ts`](src/content/types.ts): profile, experience, skills, projects, takeaways and contact. Site-wide values (banner word, description, version) are in [`src/content/site.ts`](src/content/site.ts).

- Photo: replace `public/avatar.jpg` (keep the `alt` text in `content.profile.photo`).
- CV: replace `public/cv.pdf`; the `:cv` command serves it.
- Any line containing `TODO` is flagged as a placeholder in its section header, so leftovers are easy to spot.

## Metadata and social preview

Title, description and Open Graph/Twitter tags are set in `src/app/layout.tsx` from `site.ts`. The social image is generated by `src/app/opengraph-image.tsx` and the favicon is `src/app/icon.svg`.

Set the public URL at build time so preview links resolve to the real domain:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.example npm run build
```

## Themes and design

The default theme is warm; `:theme <name>` switches to gruvbox, dracula, nord, monokai or solarized. Design tokens and rules are documented in [`docs/design.md`](docs/design.md) and implemented in `src/app/globals.css`.

## Tests

Browser and accessibility tests use Playwright and axe-core, in `tests/e2e`.

```bash
npx playwright install chromium   # first time only
npm test                          # builds, serves on :3100 and runs all specs
npx playwright test tests/e2e/accessibility.spec.ts   # a single spec
```

Tests always run against a production build, so `npm test` includes the type check.
