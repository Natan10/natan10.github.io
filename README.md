# Personal landing page

A terminal/Vim-styled personal site for Natan Moreira: experience, skills, projects and key takeaways. Built with Next.js (App Router), Tailwind CSS and a self-hosted JetBrains Mono.

## Run it

```bash
npm install
npm run dev     # http://localhost:3002
npm run build   # write the static site to out/
npm run start   # serve out/ at http://localhost:3100
npm run lint
```

## Edit the content

The page exists in English at `/` and in Brazilian Portuguese at `/pt`. Each page is built completely at build time, so every section is readable without JavaScript.

Personal content is split so the two languages cannot drift apart:

- [`src/content/shared.ts`](src/content/shared.ts) holds what does not change with the language: names, job titles, stacks, skill levels, links and contact details. Edit these once.
- [`src/content/en.ts`](src/content/en.ts) and [`src/content/pt.ts`](src/content/pt.ts) hold the translatable text (bio, location, periods, achievements, project descriptions, takeaways, skill group names), keyed by the ids in `shared.ts`. A missing or extra key is a type error, so `npm run build` fails.
- Interface text (labels, `/help` descriptions, error messages) lives in [`src/lib/dictionaries/en.ts`](src/lib/dictionaries/en.ts) and [`src/lib/dictionaries/pt.ts`](src/lib/dictionaries/pt.ts). Command names stay in English; their descriptions are in the dictionaries.
- Site-wide values (banner word, version) are in [`src/content/site.ts`](src/content/site.ts).

Visitors switch with the `EN | PT` toggle in the top-right corner of the hero or the `/language` command (`/language pt`, `/language en`; `:language` works too). Switching is a plain navigation to the other route, which opens at its top.

- Photo: replace `public/avatar.jpg` (keep the alt text in `photoAlt` of each language's text).
- CV: replace `public/cv.pdf`; the `:w` command serves it. The CV stays English on both pages.
- Any line containing `TODO` is flagged as a placeholder in its section header, so leftovers are easy to spot.

## Metadata and social preview

Title, description, canonical address and language alternates are built per language by `src/lib/site-metadata.ts` and set in each language's layout (`src/app/(en)/layout.tsx`, `src/app/(pt)/pt/layout.tsx`). The social image is generated by `src/lib/social-image.tsx` and each language route owns its image file; the favicon is `src/app/icon.svg`.

The default public URL is `https://natan10.github.io/`. To build for another domain, set it at build time:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.example npm run build
```

## Themes and design

The default theme is warm; `:theme <name>` switches to gruvbox, dracula, nord, monokai or solarized. Design tokens and rules are documented in [`docs/design.md`](docs/design.md) and implemented in `src/app/globals.css`.

## Tests

Browser and accessibility tests use Playwright and axe-core, in `tests/e2e`.

```bash
npx playwright install chromium   # first time only
npm test                          # builds out/, serves it on :3100 and runs all specs
npx playwright test tests/e2e/accessibility.spec.ts   # a single spec
```

Tests run against the exported static files, so `npm test` includes the production build and type check.
